## 二、判定口径（先定，后跑）

1. **字节**：`len(content.encode("utf-8"))`，不是字符数。
2. **query 正文**：用 `json.JSONDecoder().raw_decode(content)` 解析完整数组，返回的 `end` 之后即尾注。上游把 footer 拼在 JSON 外面，所以 `json.loads(content)` 本就不是契约；验收按 raw_decode 判。
3. **截断**：`warnings` 非空算“自报截断”；正文行数 `< total` 算“内容缺失”。
4. **最大有序前缀**：设实际保留 `k` 行、`next` 为第 `k+1` 行的 JSON 字节数；若 `bytes(content) + 2 + next > 16384`，则再多一行无论如何装不下 → 前缀最大。
5. **兼容**：`inspect.signature` 与上游完全一致；小输入输出逐字节一致（sha256 对比）。
6. **性能**：仅组件级，固定数据、固定重复数（20 次），报中位数与 min/max；不推断整体 Agent 提速。
